# 实现与规则边界

本插件采用参考会话文档中的文墨天机 2.5.9 三合天盘基础公式。61 组数值表和 82 项星曜名保存在 `data/`；原表名、一基占位及来源行号见 [provenance.json](provenance.json)。星曜 ID、宫位与天干地支均保留一基索引。

## 分层

`calendar_core.py` 验证与归一化日期，保留原输入、钟表时间、计算时间、实际农历和子时后的安星农历。`rules.py` 保存不可变配置并选择表。`engine.py` 实现纯计算，`commands.py` 解析用户参数，`renderer.py` 绘图与格式化，`main.py` 接入 AstrBot 并约束并发。1.6.0 起，命盘由 `archive_store.py` 在插件外保存；渲染图片仍只在内存生成。

`access.py` 实现默认关闭的群白名单，使用平台实例与群 ID 的组合生成 KV 键，群授权由显式开启指令写入。框架 KV 持久化布尔授权；关闭删除该键，未授权、异常值和读取失败均不放行。事件的群、平台与管理员身份在第一次 await 前捕获，查询白名单后才进入参数解析、计算或渲染。只有群主、群管理员或 AstrBot 管理员可管理本群授权；非 OneBot 平台使用 AstrBot 管理员身份。

`modern_renderer.py` 保存显示模型与现代东方风绘制逻辑，采用用户参考图的外围十二宫、中央资料、竖排星曜、底部宫名与年龄、左右宫干支及十二神布局。星曜类别与四化徽标独立，显示分类不改写计算引擎的分组或星曜位置。白天主星、辅星、煞星、杂曜分别为红、紫、墨黑与蓝，夜间分别为暖金、浅青、暗白与雾蓝；视觉煞星清单见 `MALEFIC_IDS`。每个星曜实例独立显示，保留正副星和自化。中宫四柱缩为年、月、日、时四列，每列上干下支，各字按五行着色；不扩展藏干、生克关系或八字起运。

每宫最多展示五个同宫流年年份及虚岁：按年支落宫，每十二年重复。无流盘时从出生后的最早对应年开始；有流盘时取所选年附近的序列，确保选中年在其正确宫位出现。年份受支持区间和十二大限年龄上限约束。流年按目标农历年标注，春节前不能用目标公历年份替代。显示模型与绘制不改变原始排盘结果。

1.4.0 自化只在宫界绘制箭头：离心沿外框指向盘外，向心沿靠盘心的内框指向盘心，均保留跨框线的表达，不画在宫内或星曜旁。方向由当前宫位相对盘心的位置确定。上、下边的箭头槽避开宫名及身宫标记；左、右边的标记按数量均分，并给四化字样留出间隔。内框箭头在宫位和中央背景绘制结束后叠加，避免被后绘制的区域遮盖。箭头由线段和三角形绘制，不依赖字体中的箭头字符。

`themes.py` 使用冻结的色卡对象，分别保存昼夜背景、文本、星曜、五行与四化颜色；每次渲染独立创建 Painter，无修改全局颜色。`image_theme` 配置提供默认值，指令、LLM 与 CLI 通过共同解析器接受 `主题=白天|夜间|day|night`，选择只传递到图片入口，不写入历法、命盘计算字段或规则快照。中宫四柱和右下角干支分别查自己的五行颜色。星曜处的生年、大运、流年四化均只标单字，来源分别用红、绿、蓝底色区分；各宫来源标签和中宫三层四化说明沿用这些来源颜色，夜间独立调整色值。自化仍在宫界绘制，不重复到星曜旁。顶部保留无分类注释的布局。

字号调整保持原字体、常规字重及布局密度，只小幅增加星曜、庙旺、年份等字号，不使用加粗字体或额外的宫内箭头留白。完整计算、自化来源、文字盘和 LLM JSON 保持不变。

参考图仅用于布局设计，未复制图中软件品牌、图像资源、字体、按钮或交互功能。

参数解析兼容 12 位 `YYYYMMDDHHMM` 与 14 位 `YYYYMMDDHHMMSS`，先拆为日期和时刻再使用既有严格校验。分开输入时也支持 `HHMM`／`HHMMSS`。`运限=0` 选择童限，`运限=1`—`12` 选择第几个大限；`大限=`、`大运=` 在参数解析时规范为同一选项，重复填写同义选项也会拒绝。运限选项与流年、流盘、流时互斥，纯运限不假定一个流年。不会补造缺失时间或性别，手动指令、别名、LLM 工具和离线入口共用解析器与计算路径。

## LLM 工具、缓存与永久档案

`main.py` 通过官方 `filter.llm_tool` 注册 `ziwei_paipan` 与 `ziwei_get_chart`，使用真实消息事件确认群授权与发送者，不接受工具参数里的群或用户身份。工具不会调用开关管理路径，不停止 LLM 事件，返回 JSON 供模型继续回答。

`llm_data.py` 按平台实例、群、发送者缓存最近一份命盘，使用归档 ID 与 15 分钟有效期，最多 128 份；不调用 KV 持久化出生资料。读盘不续期，新盘替换缓存但不覆盖档案；关闭群功能清除该群缓存，重载清除全部缓存。过期后回查本人永久档案。手动指令与工具共用参数校验、计算及并发限制，并在计算结束后复核授权。

`analysis_facts.py` 只在计算结果上构造三方四正、气数位、层级宫名和宫干飞化关系；本命读盘剥离流层，年度读盘剥离月日时。`knowledge.py` 按作用域、主题、星曜与已实现能力检索来源明确的总结，不能回写计算规则。`reading_service.py` 绑定真实问题和反馈，`delivery_capture.py` 观察本次事件的实际发送调用，`summary_worker.py` 使用空模型上下文独立总结。流程、存储及边界见 [归档与反馈协议](READING_ARCHIVE.md)。

JSON 不重复导出全局星曜数组，各宫保留星曜的独立实例、原始分类及图面分类、庙旺、正副标志、所有已计算四化和自化。整体摘要、出生换算、规则快照、十二大限与所选运限或流盘随宫位查询一起返回。图片称“大运”的层级在 JSON 与引擎中保持 `大限` 键，来源名称不改写计算数据。工具可按用户要求将图片发送到预先捕获的当前会话，但默认只返回数据；渲染或发送失败不替代计算事实。

命宫 `wrap12(M-H+3)`，身宫 `wrap12(M+H+1)`。五行局按生年干组与命宫地支对查表，紫微按日数除局数的补数奇偶安星，天府与紫微镜像。宫名沿地支递减。阳男阴女大限顺行，阴男阳女逆行，小限另按男顺女逆。

主辅星分别保存生年、命宫、日干及运限四化；离心自化取本宫干，向心取对宫干。普通杂曜不执行这条四化逻辑。农历输入也生成日干四化，属于本插件扩展。共享规则表从不由 getter 原地修改。

## 运限

大限以五行局数虚岁起，每宫十年；童限为一岁至起限前一年，取本命夫妻宫。`apply_decade(natal, index)` 按 0 童限、1—12 大限选择，返回新的盘，不修改传入对象；`flow.kind=decade`，`age` 为所选运限的起始虚岁，`start_year`、`end_year` 按安星农历生年与虚岁换算，保留完整 `decade`，`layers` 仅含 `大限`。纯运限没有选定流年或日期，`year`、`target` 为 null，不生成流年四化或小限层。

流年命宫在目标农历年支；流月从子年斗君顺数，流日按目标农历日序，流时继续顺数时支。目标日期完整重算，不依赖 UI 先后点击顺序。`apply_flow` 保持既有大限、小限与年、月、日、时算法，返回 `flow.kind=annual` 的新对象，清除旧运限信息而保留本命。

运限仅含宫名、命宫、四化与大限范围，不新增限昌限曲等限流曜。运限图片叠加本命与所选大运，流年图片叠加本命、当年大运与流年，各层宫名在对应宫位标注，各层四化在相应本命星实例旁标注。文字与 JSON 保留已计算的全部层级，不因图片只重点显示这三层而丢失小限或日期流盘层。

## 人生变动图谱 P1

聊天入口的省空格适配独立于历法解析。`compact_commands.py` 只在明确的命令、历法、出生数字、中文性别及 `名称=值` 边界补空格，未知后缀保留给原严格解析器拒绝，不推测缺失资料。`compact_filter.py` 使用 AstrBot 自定义过滤器，要求真实事件已经由框架唤醒；指令名后已有空白的消息交给原 CommandFilter，避免重复响应。处理器不改写原消息或全局前缀，也不新增命令别名。

紧凑写法在原群授权、个人档案和并发流程内执行；参数错误静默退出，不持久化输入或写入日志。认领的紧凑指令设置停止传播及禁止默认 LLM 回退，未命中的自然聊天不修改事件。完整标准写法保留原有提示。控制词必须与已有命令完整匹配，`紫微开启新生活` 等文本不作为开关命令。

`life_atlas.py` 在 `engine.py` 之外编排出生年至 60 虚岁所在大限末年的逐年计算，使用 `build_facts` 中已实现的宫位和本命固定宫干飞化。`life_atlas_commands.py` 复用原出生解析；`life_atlas_renderer.py` 独立绘图；`life_atlas_service.py` 负责真实事件授权、队列、归档及图片交付。普通排盘和 LLM 工具不自动执行图谱。

筛选版本为 `P1-common-target-v1`，结构版本为 `ziwei-life-atlas-v1`。当大限命宫和流年命宫处于不同地支宫位，且两者宫干飞化共同落入同一个大限官禄、夫妻、迁移或田宅宫，保留两路来源宫干、星曜、四化及目标宫位。流年一路按所在宫位的本命宫干取飞化，不能混为目标年份年干四化。童限不判断事件；官禄主题在虚岁 18 前显示学习评估，之后显示工作职责，这是展示映射。

只将同主题、同大运、同目标地支且连续命中的农历年份合并。每个年度命中保留原始依据，图片按编号与时间轴对应；密集节点及长依据自动增加高度，不省略节点。出生年按安星农历年计虚岁 1，五行局决定末年为虚岁 61—65；全范围超出历法支持时在扫描前拒绝。

来源快照为知识库 `hl-method`、`hl-stems`、`hl-annual`、`hl-decade-inside`、`hl-context` 及其来源、条件、例外和版本。P1 是自定结构预览启发式，不是古籍的重大事件公式；知识命中不表示全部适用条件已成立。没有执行完整星情庙旺会照、现实职业关系、重大事件阈值、月日时或独立限流曜判断；不输出准确率或具体事件断语。没有命中不表示没有事件。

虚构资料 `1990-06-15 08:30 男` 在默认规则下覆盖 1990—2053 农历年、虚岁 1—64，19 条年度命中合并为 15 个窗口。此结果只作为当前 P1 算法回归和图面预览，不构成命理预测效果或真实平台验收。

## 管理员 AI 辅助定盘

1.8.0 的管理员 AI 辅助定盘由本插件独立编排，具体流程如下；不复现或宣称已通过原程序自动定盘验收。

`rectification_commands.py` 解析常规空格格式的日期、性别与可选 `时辰=辰,巳,午`，复用 `commands.parse_request` 的历法、位置及规则配置校验；不填时辰表示当地钟表全天，子时包含当天早子和晚子两个区间。只支持出生选项与图片主题，拒绝流年、流盘、流时及运限混用；不扩展紧凑输入过滤器。

`rectification.py` 在引擎外生成候选：用与历法层相同的经度、均时差及秒级舍入计算校正时钟，对时支变化、午夜、23 时换日边界做二分定位，并将同一 UTC 对应的节气四柱边界加入分段。每段调用真实 `build_chart`，按安星参数、实际农历、安星农历与四柱判断是否可合并，保留所有钟表半开区间。候选不固定为十二张，上限 32；任一所选范围校正后越过支持日期则整批拒绝，不静默排除。每张盘的出生时刻只是所在范围的代表值，`engine.py` 及原有安星规则不变。

`rectification_service.py` 同时检查真实事件的 `astrbot_admin` 和当前群白名单。仅显式 `/紫微 定盘` 指令创建候选批次；帮助可查看，群主／群管理员角色不代替 AstrBot 管理员权限，也不能用工具参数指定其他群或用户。创建之后由用户 @机器人明确开始逐轮定盘；新问题与普通解盘共享滚动一小时 6 次额度，同一真实消息的分批读取去重。纯反馈只修正已取得资料，不增加主题或年份分析；不存在 AI 建候选批次或确认候选工具。

主 AI 通过 `ziwei_rectification_context` 按主题每批至多读取两个候选，复用 `build_facts` 与知识查询。大运序号、农历流年明确时使用既有 `apply_decade`／`apply_flow`，不得把公历经历年份直接当成农历流年。评价只包含支持、冲突、未知、真实反馈序号与知识 ID；支持或冲突须同时有反馈与已读取的知识依据。全部候选保留，证据不足可以不选出唯一结果。普通读盘与定盘不能关联同一次回答。

`rectification_store.py` 使用现有插件外数据库和事务，独立保存候选、会话、问答、知识与评价，不写入普通命盘列表或最近命盘缓存。只有显式 `/紫微 定盘 确认 c01 [会话ID]` 才把该候选另存到 `charts` 并设为当前盘，保留候选范围与 `representative_only` 标记。多个进行中会话须提供 ID；取消不删除永久档案，已确认选择不允许被另一候选覆盖。

主 AI 判断真实反馈闭环后，独立总结消费者只读取本会话候选计算摘要、评价、知识快照和问答，调用已有 AstrBot provider，`contexts=[]`。它不发群消息、不写主对话、不保留临时 Agent，也不读取其他会话。总结状态、失败重试与原始过程一并归档；管理员选定只能描述为选择，不能升级为出生时刻得到验证。持久化细节见 [归档与反馈协议](READING_ARCHIVE.md#定盘会话与独立归档)。

## 相对于原程序的差异

- 历法改用固定版本 lunar-python，真太阳时采用经度修正和独立均时差近似。均时差用 UTC 儒略世纪；节气四柱年、月按同一 UTC 转为北京时间比较，日、时按选定计算时间比较。夏令时由用户填写出生当时的实际 UTC 偏移，不推断历史时区。
- 原公历入口与农历辅助入口不同；本插件统一转换为出生钟表日期后校正。农历日按真实月长验证，不复现 AS 中可疑的端点拒绝条件。
- 闰月处理在子时归一化之后；闰十二月向后取月限制为十二月。晚子时以完整公农历转换推进一天，保留闰月和年末换日。
- 地劫先规范化落宫再查庙旺，不复现反编译 AS 子时读取第 0 列的疑似异常。
- 长生、博士、岁前、将前按本命年干支生成，此版不会随流盘改为另一套序列。
- 默认三合基础杂曜，没有飞星／四化专属门控与显示皮肤；`minor_stars` 仅是本插件杂曜开关。
- 不支持公元前、天地人盘、原程序自动定盘、旧安星码、四柱反查、八字起运或原命例库；当前定盘为上述管理员逐轮问答辅助比较。

公式样例与恢复函数回归只证明局部样例相符；全盘兼容需从原程序独立记录输入、安星码、时间、全星曜、庙旺、运限及四化逐项比较，当前没有这项验收结果。
