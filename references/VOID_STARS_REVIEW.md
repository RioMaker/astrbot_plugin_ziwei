# 截空、旬空“副”标记文献复核

复核日期：2026-11-05。对象为 2.0.2 默认配置 `void_rule=2`，不是所有流派、所有空曜取法的通用结论。

## 结论与说明修正

当前截空、旬空的成对落宫及正副次序符合下列文献规则，未发现默认取法的错位或颠倒。“副”对应傍空／旁空，有文献依据，也不表示“辅星”类别。需要修正的是旧 README 中“不是强弱评级”的绝对说法：文献确实区别两者的论用；软件没有据此实现数值权重，不等于文献不分轻重。

本次不改计算表、引擎、历法、图面或其他空曜配置，也不删除傍空。只补充可追溯说明与独立期望测试。

## 文献与版本边界

1. [《紫微斗數全書》卷二，维基文库转录](https://zh.wikisource.org/wiki/紫微斗數全書/卷二)：在“安截路空亡诀”“安旬中空亡诀”列出按本生年取用的成对宫位，分别对应下方五组、六旬表。这两段本身没有交代正、傍的取舍，不能仅凭这两段就声称古籍统一规定“副”的含义。
2. [王亭之《安星法及推断实例》，公开扫描本](https://github.com/Copoet/md/blob/133b640d4c8fedf61a9d6545ec8c0c573514e34c/《安星法及推断实例》—王亭之.pdf)：书页 56（PDF 第 31 页右半），第 16 节“安截空诀”、第 17 节“安旬空”。目视核对原页：副称傍空，正、傍按出生年干与宫位地支的阴阳分配；对截空区别论用轻重，旬空沿用同例。这支持保留正副位置，不支持给两者相同作用或自定量化系数。
3. [王亭之《中州派紫微斗数深造讲义》，公开电子排印本](https://github.com/Copoet/md/blob/133b640d4c8fedf61a9d6545ec8c0c573514e34c/《中州派紫微斗数深造讲义》—王亭之.pdf)：PDF 第 322 页，截空、旬空正旁说明。目视核对后确认正旁分配与上述相同，但推断取用限定在正空。不能把这个口径与前书合并成“所有文献均以相同方式论副空”。

后两份为公开镜像，不是作者或出版社网站；第二份为扫描页，第三份为电子排印，未据此认定出版年份或版次。已核对相关页面，避免只依赖搜索摘要或 OCR。镜像固定到仓库提交 `133b640d4c8fedf61a9d6545ec8c0c573514e34c`，下载文件 SHA-256 分别为：

- 《安星法及推断实例》：`bf0dbef566b5be795602e6eda18e9c632193bdd49913736da641d2e9a563b4fe`
- 《中州派紫微斗数深造讲义》：`513e3d068040efe3684eb3c0e44cf6e447787670bbf5d618f022da2d6c55231b`

## 默认取法的独立期望

阳干为甲、丙、戊、庚、壬，阳支为子、寅、辰、午、申、戌；其余为阴。选定两宫后，地支与出生年干同阴阳者为正空，另一宫为傍空。判断使用出生年干，不使用性别或该宫天干。

截空的五组基础位置为甲己申酉、乙庚午未、丙辛辰巳、丁壬寅卯、戊癸子丑。结合正傍规则得到：

| 生年干 | 正截空 | 傍截空（图中“副”） |
| --- | --- | --- |
| 甲 | 申 | 酉 |
| 乙 | 未 | 午 |
| 丙 | 辰 | 巳 |
| 丁 | 卯 | 寅 |
| 戊 | 子 | 丑 |
| 己 | 酉 | 申 |
| 庚 | 午 | 未 |
| 辛 | 巳 | 辰 |
| 壬 | 寅 | 卯 |
| 癸 | 丑 | 子 |

旬空先按出生干支所属旬取两宫，再用相同阴阳规则区分正傍：

| 所属旬 | 旬空两宫（尚未区分正傍） |
| --- | --- |
| 甲子旬 | 戌、亥 |
| 甲戌旬 | 申、酉 |
| 甲申旬 | 午、未 |
| 甲午旬 | 辰、巳 |
| 甲辰旬 | 寅、卯 |
| 甲寅旬 | 子、丑 |

例如虚构演示盘 1990 年六月（庚午年），正截空在午、傍截空在未，正旬空在戌、傍旬空在亥；1993 年六月（癸酉年），正截空在丑、傍截空在子，正旬空在亥、傍旬空在戌。正傍空不随性别切换。

## 与实现的对照及验证边界

- `engine.py` 的截空（ID 77）读取 `_AX_JK_ARR2`，旬空（ID 78）由生年干支求两宫后按年干阴阳排序；两者均只把第二个实例标为 `secondary=True`。逐项对照后与上述独立期望一致。
- [tests/test_void_stars.py](../tests/test_void_stars.py) 的期望表直接按上述文献整理，不从引擎表生成。虚构的 1984—2043 年六月输入覆盖六十甲子，逐一核对 120 组截空、旬空的正傍位置、独立实例与所属宫。
- 另有 5 例覆盖立春前后、农历换年及两种晚子换日设置，防止把节气四柱的年干支误用于这两颗本命空曜。这部分检验插件既有历法约定，不表示上述文献已经统一裁决晚子换日争议。
- `void_rule=1`、`void_rule=3` 不属于本次文献复核范围；未据本次结果改写它们或扩展为所有流派结论。既有数值表的来源仍见 [provenance.json](provenance.json)，本次外部文献比对不能替代原软件 GUI、真实 AstrBot 或线上验证。
